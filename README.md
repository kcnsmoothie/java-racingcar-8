# java-racingcar-precourse
# 기능 요구 사항 정리

## 입력

- [X]  경주할 자동차 이름 입력
    - 중복된 값을 입력하는 경우를 유연하게 처리할 수 있도록 `LinkedHashSet`을 사용
- [X]  시도 횟수 입력

## 입력 예외 처리

- 자동차 이름
    - [X]  자동차 이름이 5자 이상일 경우
    - [X]  빈 문자열이나 null값을 입력한 경우
- 시도 횟수 입력
    - [X]  음수나 0을 입력할 경우
    - [X]  빈 문자열이나 null값을 입력할 경우

→ 잘못된 값일 시에 `IllegalArgumentException`을 발생

## 비즈니스 로직

- 입력값 분리
    - [X]  쉼표(,) 기준으로 입력값 분리
    - [X]  분리한 입력값 저장
- 게임 기능
    - [X]  입력받은 자동차 수만큼 객체 생성
    - [X]  한 라운드를 진행할 때 
      무작위 값이 4 이상일 경우, 전진 / 무작위 값이 4 미만일 경우, 멈춤

    - [X]  입력 차수만큼 게임 실행
    - [X]  최종 우승자 검증

## 출력

- 차수별 실행 결과
    - [X]  자동차 이름, 차수 출력
- 우승자 안내 문구
    - [X]  단독 우승일 경우
    - 우승 자동차 이름 출력
    - [X]  공동 우승일 경우
    - 우승 자동차 이름 출력
    - 쉼표 기준으로 구분
