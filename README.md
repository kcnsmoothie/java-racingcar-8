# java-racingcar-precourse

## 기능 구현 사항
### 입력
- [X] 경주할 자동차 이름
- [X] 시도할 횟수

### 기능 구현
- [X] 구분자(,)단위로 자동차 이름 구분
- [X] 자동차 객체 생성
  - 이름
  - 전진한 횟수
- [X] 게임 한 차수 진행 
  - 0에서 9 사이에서 무작위 값 선출
  - 무작위 값이 4 이상일 경우, 전진
  - 아닐 경우, 멈춤
- [ ] 최종 우승자 계산 기능
  - 자동차 객체들의 전진 횟수 비교

### 출력
- [ ] 차수별 실행 결과
  - 매 차수가 끝날 때다 보여줘야함
  - 차수별로 한줄 띄우기
  - ex) 시도할 횟수가 n회 이면 n번 출력
- [ ] 우승자 안내 문구
  - 단독 우승자일 경우
  - 공동 우승자일 경우
    - 쉼표(,) 단위로 구분해서 출력

### 예외
- 예외 발생 시, IllegalArgumentException을 발생시킨 후 종료
- 자동차
  - [ ] 자동차 이름이 공백일 때
  - [ ] 자동차 이름이 중복될 때
  - [X] 자동차 이름이 5자 초과일 때
  - [X] 쉼표 앞뒤로 공백 존재(유연하게 처리해줄 예외)

- 시도할 횟수
    - [ ] 시도할 횟수가 공백일 때
    - [ ] 시도할 횟수가 문자열일 때
