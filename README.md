# java-racingcar-precourse
# 기능 요구 사항 정리

## 입력

- [ ]  경주할 자동차 이름 입력
- [ ]  시도 횟수 입력
- [ ]  자동차 이름은 쉼표(,)를 기준으로 구분

## 입력 예외 처리
- [ ]  이름은 5자 이하
    - 5자 이상 인지, 공백값인지 검사

→ 잘못된 값일 시에 `IllegalArgumentException`을 발생

## 게임 서비스 로직

- [ ]  입력 차수만큼 게임 실행
- [ ]  무작위 값이 4 이상일 경우, 전진 / 무작위 값이 4 미만일 경우, 멈춤
- [ ]  각 차수가 끝날 때마다 우승자 및 우승 횟수 저장

## 출력

- [ ]  차수별 실행 결과
    - 자동차 이름, 차수 출력
- [ ]  우승자 안내 문구

  단독 우승일 경우

    - 우승 자동차 이름 출력

  공동 우승일 경우

    - 우승 자동차 이름 출력
    - 쉼표 기준으로 구분
